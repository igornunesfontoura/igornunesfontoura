# Olá, eu sou o Igor Nunes 👋

Sou de Porto Alegre/RS e crio software por conta própria: observo o meu dia a dia, percebo onde uma ferramenta poderia ajudar e coloco a mão na massa até a ideia sair do papel. Faço o curso Técnico em Desenvolvimento de Sistemas no Senac, onde me conectei com o Java, e antes disso aprendi Python, JavaScript, HTML e CSS em cursos e vídeos. Meu objetivo é criar projetos que as pessoas realmente usem e ter liberdade para continuar criando.

## Projetos em destaque

**[overcam](https://github.com/igornunesfontoura/overcam)** · Python\
Toca um clipe de vídeo e áudio por cima da webcam durante chamadas no Linux, usando v4l2loopback e PipeWire.

**[SongLog](https://github.com/igornunesfontoura/SongLog)** · Java Swing + MySQL\
Aplicação desktop para avaliar álbuns faixa por faixa. Nasceu como Projeto Integrador do curso técnico no Senac.
